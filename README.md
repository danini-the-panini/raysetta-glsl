# Raysetta GLSL

Implementation of [Raysetta](https://github.com/danini-the-panini/raysetta) on the GPU using OpenGL.

## Build

```sh
  $ make
```

## Run

```sh
  $ ./main path/to/scene.json
```

Click and drag to move camera, scroll to zoom.

⬆️/⬇️ controls number of samples.

⬅️/➡️ controls max depth.

`R` to redraw.
